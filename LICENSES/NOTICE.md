# glyphfox universe: third party notices

glyphfox-universe gives one API over 414,952 icons from 245 open license icon sets, as packaged by Iconify in [@iconify/json](https://github.com/iconify/icon-sets) 2.2.547 (MIT) and the @iconify-json/<prefix> packages. Every set keeps its own license, listed below with its authors and links. The license texts are in this folder, exactly as each set publishes them (files ending in .license). The code of glyphfox-universe is MIT, see [LICENSE](../packages/universe/LICENSE).
