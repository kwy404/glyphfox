    Saída

    Linguagem

    Uma linguagem de texto pequena para ícones na grade de 24. Cada comando vira uma forma, as transformações são aplicadas nos pontos e o resultado passa no lint dos ícones.

    # note
    Comentários vão até o fim da linha.
    name sun tags bright category weather
    Nome, tags e categoria do ícone.
    let r = 4
    Dá nome a um número; expressões aceitam + - * / e parênteses.
    circle cx cy r
    Círculo pelo centro e pelo raio.
    ellipse cx cy rx ry
    Elipse pelo centro e pelos dois raios.
    rect x y w h radius r
    Retângulo, com cantos arredondados opcionais.
    line x1 y1 x2 y2
    Linha reta entre dois pontos.
    polyline x y x y polygon x y x y x y
    Lista de pontos aberta ou fechada.
    arc cx cy r from a to b
    Arco em graus, 0 no meio dia, no sentido horário.
    path "M4 12h16"
    Dados de path SVG direto.
    dot x y
    Um ponto redondo, como um olho.
    group move dx dy rotate a around cx cy scale s { }
    Move, gira ou escala as formas de dentro.
    mirror x at 12 { } mirror y mirror xy
    Desenha as formas e o reflexo delas.
    repeat n around cx cy step deg { }
    Repete as formas em volta de um centro.
    duotone { }
    Formas fechadas unidas na camada duotone.

    Favicon animado

    Toque um estado vivo ou um morph na aba do navegador. Um runtime pequeno desenha os quadros num canvas, e o SVG e o PNG estáticos ficam como alternativa.

    Cursor CSS

    Arquivos PNG em 32 e 64 px com um halo que aparece em qualquer página, um hotspot em pixels CSS e o CSS do cursor com image-set.

    Passe o ponteiro aqui para testar o cursor

    Plotter de caneta

    Um SVG de linha única só com traços e sem preenchimentos, na ordem com menos deslocamento da caneta, e G-code com as suas velocidades e comandos de caneta.

    Origem

    Linhas cheias desenham, linhas tracejadas são movimentos com a caneta erguida.

    STL para impressão 3D

    Extrude qualquer ícone numa malha fechada com base plana, a espessura que você precisa e um chanfro opcional. O mesmo código roda no Node com glyphfox stl.
