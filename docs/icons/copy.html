interface

Copy icon

Copy is an original glyphfox icon from the interface set, drawn on the 24 by 24 grid with 2 shapes. Its closed shapes also give it a solid style, generated at build time. It belongs to a hand tuned morph pair, shown below. Tags: duplicate, clone, clipboard, paste.

Customize in the icon browser

Sizes, weights and styles

Every glyphfox icon renders along three axes. The stroke grows a little below 24 px so small icons keep their presence.

Morph pair

glyphfox morphs any icon into any other. These pairs are tuned by hand. Hover the preview to play the CSS only morph that toSvg returns with morphTo.

With a modifier badge

Add a badge in any corner with modifier or the name syntax. The icon is cut around the badge, so the result still passes the icon rules.
