text

Notebook icon

Notebook is an original glyphfox icon from the text set, drawn on the 24 by 24 grid with 3 shapes. Its closed shapes also give it a solid style, generated at build time. Tags: notes, journal, spiral, diary, education.

Customize in the icon browser

Sizes, weights and styles

Every glyphfox icon renders along three axes. The stroke grows a little below 24 px so small icons keep their presence.

Copy the code

Pick a format. Each snippet uses the package entry point for that stack; the props work the same everywhere.

Code formats
App.jsx
import { NotebookIcon } from 'glyphfox/react';

<NotebookIcon />
App.vue
<script setup>
import { NotebookIcon } from 'glyphfox/vue';
</script>

<template>
  <NotebookIcon />
</template>
App.svelte
<script>
  import { NotebookIcon } from 'glyphfox/svelte';
</script>

<NotebookIcon />

import { GlyphFoxIcon, provideGlyphFox } from 'glyphfox-angular';
