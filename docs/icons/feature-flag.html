Feature flag icon

Feature flag is an original glyphfox icon from the development set, drawn on the 24 by 24 grid with 4 shapes. Its closed shapes also give it a solid style, generated at build time. Tags: feature flag, toggle, rollout, release, experiment.

Customize in the icon browser

Sizes, weights and styles

Every glyphfox icon renders along three axes. The stroke grows a little below 24 px so small icons keep their presence.
