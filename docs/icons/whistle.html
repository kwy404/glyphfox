sports

Whistle icon

Whistle is an original glyphfox icon from the sports set, drawn on the 24 by 24 grid with 3 shapes. Its closed shapes also give it a solid style, generated at build time. Tags: whistle, referee, coach, signal, sport.

Customize in the icon browser

Sizes, weights and styles

Every glyphfox icon renders along three axes. The stroke grows a little below 24 px so small icons keep their presence.

Copy the code

Pick a format. Each snippet uses the package entry point for that stack; the props work the same everywhere.

App.jsx
import { WhistleIcon } from 'glyphfox/react';

<WhistleIcon />
App.vue
<script setup>
import { WhistleIcon } from 'glyphfox/vue';
</script>

<template>
  <WhistleIcon />
</template>
App.svelte
<script>
  import { WhistleIcon } from 'glyphfox/svelte';
