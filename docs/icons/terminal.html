Terminal icon

Terminal is an original glyphfox icon from the development set, drawn on the 24 by 24 grid with 3 shapes. Its closed shapes also give it a solid style, generated at build time. Tags: console, shell, command line, prompt.

Customize in the icon browser

Sizes, weights and styles

Every glyphfox icon renders along three axes. The stroke grows a little below 24 px so small icons keep their presence.

Copy the code

Pick a format. Each snippet uses the package entry point for that stack; the props work the same everywhere.

Code formats
App.jsx
import { TerminalIcon } from 'glyphfox/react';

<TerminalIcon />
App.vue
<script setup>
import { TerminalIcon } from 'glyphfox/vue';
</script>

<template>
  <TerminalIcon />
</template>
App.svelte
<script>
  import { TerminalIcon } from 'glyphfox/svelte';
</script>

<TerminalIcon />
app.component
import { GlyphFoxIcon, provideGlyphFox } from 'glyphfox-angular';

<gf-icon name="terminal"></gf-icon>
index.html
<glyph-fox name="terminal"></glyph-fox>
index.html
<script src="https://cdn.jsdelivr.net/npm/glyphfox@1"></script>

<glyph-fox name="terminal"></glyph-fox>
