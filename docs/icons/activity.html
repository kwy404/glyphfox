Activity icon

Activity is an original glyphfox icon from the data set, drawn on the 24 by 24 grid with one shape. It is an open line drawing, so the solid style keeps the outline look. Tags: pulse, heartbeat, monitor, health, signal.

Customize in the icon browser

Sizes, weights and styles

Every glyphfox icon renders along three axes. The stroke grows a little below 24 px so small icons keep their presence.

Copy the code

Pick a format. Each snippet uses the package entry point for that stack; the props work the same everywhere.

App.jsx

<ActivityIcon />
App.vue

import { ActivityIcon } from 'glyphfox/vue';
</script>

<template>
  <ActivityIcon />
</template>

  import { ActivityIcon } from 'glyphfox/svelte';
</script>
