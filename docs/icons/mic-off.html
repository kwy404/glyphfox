Mic off icon

Mic off is an original glyphfox icon from the media set, drawn on the 24 by 24 grid with 5 shapes. It is an open line drawing, so the solid style keeps the outline look. Tags: microphone, mute, muted, silent.

Customize in the icon browser

Sizes, weights and styles

Every glyphfox icon renders along three axes. The stroke grows a little below 24 px so small icons keep their presence.
