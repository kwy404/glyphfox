commerce

Pants icon

Pants is an original glyphfox icon from the commerce set, drawn on the 24 by 24 grid with 2 shapes. Its closed shapes also give it a solid style, generated at build time. Tags: trousers, jeans, clothing, fashion, apparel.

Customize in the icon browser

Sizes, weights and styles

Every glyphfox icon renders along three axes. The stroke grows a little below 24 px so small icons keep their presence.

Copy the code

Pick a format. Each snippet uses the package entry point for that stack; the props work the same everywhere.

Code formats
App.jsx
import { PantsIcon } from 'glyphfox/react';

<PantsIcon />
App.vue
<script setup>
import { PantsIcon } from 'glyphfox/vue';
</script>

<template>
  <PantsIcon />
</template>
App.svelte
<script>
  import { PantsIcon } from 'glyphfox/svelte';
</script>

<PantsIcon />
app.component
import { GlyphFoxIcon, provideGlyphFox } from 'glyphfox-angular';

<gf-icon name="pants"></gf-icon>
index.html
<glyph-fox name="pants"></glyph-fox>
index.html
<script src="https://cdn.jsdelivr.net/npm/glyphfox@1"></script>

<glyph-fox name="pants"></glyph-fox>
