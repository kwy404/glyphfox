    Langage

    Un petit langage textuel pour les icônes sur la grille de 24. Chaque commande devient une forme, les transformations sont appliquées aux points et le résultat passe le lint des icônes.

    # note
    Les commentaires vont jusqu'à la fin de la ligne.
    name sun tags bright category weather
    Nom, étiquettes et catégorie de l'icône.
    let r = 4
    Nomme un nombre ; les expressions acceptent + - * / et les parenthèses.
    circle cx cy r
    Cercle défini par son centre et son rayon.
    ellipse cx cy rx ry
    Ellipse définie par son centre et ses deux rayons.
    rect x y w h radius r
    Rectangle, avec des coins arrondis en option.
    line x1 y1 x2 y2
    Ligne droite entre deux points.
    polyline x y x y polygon x y x y x y
    Liste de points ouverte ou fermée.
    arc cx cy r from a to b
    Arc en degrés, 0 à 12 h, dans le sens horaire.
    path "M4 12h16"
    Données de tracé SVG brutes.
    dot x y
    Un point rond, comme un œil.
    group move dx dy rotate a around cx cy scale s { }
    Déplace, fait pivoter ou met à l'échelle les formes qu'il contient.
    mirror x at 12 { } mirror y mirror xy
    Dessine les formes et leur reflet.
    repeat n around cx cy step deg { }
    Répète les formes autour d'un centre.
    duotone { }
    Formes fermées fusionnées dans le calque duotone.

    Traceur à stylo

    Un SVG en ligne unique, avec des traits seulement et aucun remplissage, ordonné pour réduire au minimum les déplacements du stylo, et du G-code avec vos vitesses d'avance et vos commandes de stylo.

    Source

    Les lignes pleines tracent, les lignes en pointillés sont des déplacements stylo levé.

    Extrudez n'importe quelle icône en un maillage étanche avec une base plane, l'épaisseur voulue et un biseau facultatif. Le même code tourne sous Node avec glyphfox stl.
