    Sprache

    Eine winzige Textsprache für Icons auf dem 24er-Raster. Jeder Befehl wird zu einer Form, Transformationen werden in die Punkte eingerechnet, und das Ergebnis besteht die Lint-Prüfung der Icons.

    # note
    Kommentare reichen bis zum Zeilenende.
    name sun tags bright category weather
    Name, Tags und Kategorie des Icons.
    let r = 4
    Benennt eine Zahl; Ausdrücke erlauben + - * / und Klammern.
    circle cx cy r
    Kreis aus Mittelpunkt und Radius.
    ellipse cx cy rx ry
    Ellipse aus Mittelpunkt und beiden Radien.
    rect x y w h radius r
    Rechteck, optional mit abgerundeten Ecken.
    line x1 y1 x2 y2
    Gerade Linie zwischen zwei Punkten.
    polyline x y x y polygon x y x y x y
    Offene oder geschlossene Liste von Punkten.
    arc cx cy r from a to b
    Bogen in Grad, 0 bei 12 Uhr, im Uhrzeigersinn.
    path "M4 12h16"
    Rohe SVG-Pfaddaten.
    dot x y
    Ein runder Punkt, wie ein Auge.
    group move dx dy rotate a around cx cy scale s { }
    Verschiebt, dreht oder skaliert die enthaltenen Formen.
    mirror x at 12 { } mirror y mirror xy
    Zeichnet die Formen und ihr Spiegelbild.
    repeat n around cx cy step deg { }
    Wiederholt die Formen um einen Mittelpunkt.
    duotone { }
    Geschlossene Formen, vereint in der Duotone-Ebene.

    Animiertes Favicon

    Spiele einen lebendigen Zustand oder ein Morphing im Browser-Tab ab. Eine kleine Runtime zeichnet die Einzelbilder über ein Canvas, und das statische SVG und PNG bleiben als Fallback erhalten.

    CSS-Cursor

    PNG-Dateien in 32 und 64 px mit einem Halo, der auf jeder Seite gut sichtbar ist, ein Hotspot in CSS-Pixeln und das Cursor-CSS mit image-set.

    Quelle

    Hotspot
    Bewege den Zeiger hierher, um den Cursor auszuprobieren

    Stiftplotter

    Ein Single-Line-SVG nur mit Strichen und ohne Füllungen, sortiert für möglichst kurze Stiftwege, und G-code mit deinen Vorschubwerten und Stiftbefehlen.

    Quelle

    Durchgezogene Linien zeichnen, gestrichelte Linien sind Leerfahrten mit gehobenem Stift.

    STL für den 3D-Druck

    Extrudiere jedes Icon zu einem wasserdichten Mesh mit flacher Unterseite, der gewünschten Dicke und einer optionalen Fase. Derselbe Code läuft in Node mit glyphfox stl.
