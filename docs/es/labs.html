Errores y advertencias

    Salida

    Lenguaje

    Un pequeño lenguaje de texto para iconos en la cuadrícula de 24. Cada comando se convierte en una forma, las transformaciones se aplican a los puntos y el resultado pasa el lint de iconos.

    # note
    Los comentarios llegan hasta el final de la línea.
    name sun tags bright category weather
    Nombre, etiquetas y categoría del icono.
    let r = 4
    Da nombre a un número; las expresiones admiten + - * / y paréntesis.
    circle cx cy r
    Círculo a partir de su centro y su radio.
    ellipse cx cy rx ry
    Elipse a partir de su centro y sus dos radios.
    rect x y w h radius r
    Rectángulo, con esquinas redondeadas opcionales.
    line x1 y1 x2 y2
    Línea recta entre dos puntos.
    polyline x y x y polygon x y x y x y
    Lista de puntos abierta o cerrada.
    arc cx cy r from a to b
    Arco en grados, con 0 a las 12 en punto y en sentido horario.
    path "M4 12h16"
    Datos de trazado SVG en bruto.
    dot x y
    Un punto redondo, como un ojo.
    group move dx dy rotate a around cx cy scale s { }
    Mueve, gira o escala las formas que contiene.
    mirror x at 12 { } mirror y mirror xy
    Dibuja las formas y su reflejo.
    repeat n around cx cy step deg { }
    Repite las formas alrededor de un centro.
    duotone { }
    Formas cerradas unidas en la capa duotono.

    Favicon animado

    Reproduce un estado vivo o un morph en la pestaña del navegador. Un pequeño runtime dibuja los fotogramas en un canvas, y el SVG y el PNG estáticos quedan como alternativa.

    Origen

    Cursor CSS

    Archivos PNG de 32 y 64 px con un halo que se distingue en cualquier página, un punto activo en píxeles CSS y el CSS del cursor con image-set.

    Origen

    Punto activo
    Mueve el puntero aquí para probar el cursor

    Plotter de pluma

    Un SVG de línea única, solo con trazos y sin rellenos, ordenado para que la pluma se desplace lo menos posible, y G-code con tus velocidades de avance y tus comandos de pluma.

    Origen

    Las líneas continuas dibujan; las discontinuas son movimientos con la pluma levantada.

    STL para impresión 3D

    Extruye cualquier icono en una malla cerrada con base plana, el espesor que necesites y un bisel opcional. El mismo código funciona en Node con glyphfox stl.
