Changelog

What changed

Every release, newest first. The same notes live in CHANGELOG.md in the repository.

All notable changes to glyphfox are documented here. The format follows Keep a Changelog and the project uses Semantic Versioning.

Unreleased

Added

  • 82 new base icons for text formatting, charts, math, health, accessibility, faces and gestures, education and science, each with categories, tags and a designed animation: the set now has 646 base icons, 43 animated, 38 display and 11 isometric icons.

1.0.0 - 2026-10-23

Added

  • The icon set: original icons on a 24 grid with categories and tags, checked by the icon lint.
  • Variable axes in every package: weight (1 to 3 with optical compensation at small sizes), corners (round or sharp) and variant (outline, duotone and a solid style generated at build time from closed shapes).
  • The morph engine: any icon into any other, hand tuned pairs, useMorph for React, useMorph for Vue, morphStore for Svelte, the morph and morph-to attributes of the web component and a CSS only fallback.
  • Fusion: fuse() combines 2 to 10 icons with the overlap, side, stack, grid, orbit, badge and inside layouts, with knockout gaps, and the result passes the icon lint.
  • Living states: draw, pop, wiggle, spin, pulse, bounce and shake on mount, hover, click or a state prop, respecting prefers-reduced-motion.
  • Modifiers: plus, minus, check, x, alert, lock, clock, sync, arrow-up, arrow-down and dot badges in any corner with knockout gaps.
  • 23 shared props with the same names in React, Vue, Svelte, Angular and the web component.
  • Packages: glyphfox (core, icons, toSvg, icons.json, sprite.svg, runtime), glyphfox/react, glyphfox/vue, glyphfox/svelte, glyphfox/web with a single file CDN build, glyphfox/tailwind (v3 and v4), glyphfox/core, glyphfox/tools and glyphfox-angular.
  • Framework packages with the same props, generated by the build, tree shakable and typed: glyphfox/solid, glyphfox/preact, glyphfox/qwik (Qwik 2), glyphfox/lit (Lit elements), glyphfox/astro (.astro components), glyphfox/native (React Native with react-native-svg, living states sampled frame by frame) and glyphfox/ember (helpers), each with an optional peer dependency.
  • glyphfox/react/server: hook free Icon and Fusion for React Server Components that ship no JavaScript; the glyphfox/react modules are marked 'use client'.
  • Framework guides and recipes for Next.js App Router, Nuxt, SvelteKit, Remix, Alpine and htmx, in the README and in the docs under frameworks/.
  • The glyphfox CLI: search, show with a terminal preview, copy in nine formats, fuse, morph, build subsets (sprite, CSS masks, package), lint and Fox-ify.
  • Icon sources: registerIconSource(prefix, source) makes prefix:name icons from other sets work in toSvg, every component, the web component and the CDN, with weight, animations, modifiers and Fusion on stroke icons and a fallback for filled icons.
  • The studio site: icon browser, live customization, sketch search, editor, Fox-ify, Fusion, brand kit and 3D.
  • Fenn illustrations (sitting, running, drawing, orbit) built from the icon geometry, README banners and the social preview.
  • Multilingual search: synonyms in English, Portuguese, Spanish, French and German, accent folding and simple plurals in search(), the new searchIcons(), the CLI (--lang) and the studio.
  • Shared collections in the studio: a share link that carries the whole collection, compressed, in its URL fragment, and live sessions where friends edit one collection together over WebRTC, paired with six words through public MQTT relays, end to end encrypted, with presence and last writer wins merging per icon.
  • Glyph script: a tiny text language for icons (circle, ellipse, rect with radius, line, polyline, polygon, arc, path, group, mirror x or y, repeat around a center) with errors at the line and column, compiled to SVG that passes the icon lint. In glyphfox/script, the glyphfox script file.gfs command and a live playground in the studio Labs page.
  • glyphfox scan [dir]: finds the icons a project uses in JS, TS, JSX, Vue, Svelte, Angular templates and HTML, builds the minimal subset as a sprite or an ES module and flags icons without an accessible label where one is needed.
  • Exports in glyphfox/export, the CLI and the studio Labs page: an animated favicon (a canvas runtime with a static fallback), CSS cursors (PNG at 32 and 64 px with a hotspot), plotter output (single line SVG ordered for minimal pen travel, and G-code with feed rates and pen up and down commands) and STL from an extruded icon (thickness and bevel).
  • Sketch search in the studio: the 24 closest icons appear while you draw, ranked in the page against a compact shape index built by scripts/labs/sketch-index.mjs (32 by 32 stroke masks expanded into distance fields, stroke direction histograms and Zernike moments).
  • The brand kit previews the whole set themed and exports one zip with themed SVG files, a sprite, CSS variables, a favicon set (ico, 16, 32, 180, 192 and 512 PNGs), app icons and a package.json skeleton.
  • The studio site in English, Portuguese (Brazil), Spanish, French and German: static pages per language with hreflang tags, a language menu in the header and the footer, and the language of the browser picked on the first visit.
