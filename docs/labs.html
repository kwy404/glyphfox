    Language

    A tiny text language for icons on the 24 grid. Every command becomes a shape, transforms are baked into the points and the result passes the icon lint.

    # note
    Comments run to the end of the line.
    name sun tags bright category weather
    Name, tags and category of the icon.
    let r = 4
    Names a number; expressions take + - * / and parentheses.
    circle cx cy r
    Circle from its center and radius.
    ellipse cx cy rx ry
    Ellipse from its center and both radii.
    rect x y w h radius r
    Rectangle, with optional rounded corners.
    line x1 y1 x2 y2
    Straight line between two points.
    polyline x y x y polygon x y x y x y
    Open or closed list of points.
    arc cx cy r from a to b
    Arc in degrees, 0 at 12 o'clock, clockwise.
    path "M4 12h16"
    Raw SVG path data.
    dot x y
    A round dot, like an eye.
    group move dx dy rotate a around cx cy scale s { }
    Moves, turns or scales the shapes inside.
    mirror x at 12 { } mirror y mirror xy
    Draws the shapes and their mirror image.
    repeat n around cx cy step deg { }
    Repeats the shapes around a center.
    duotone { }
    Closed shapes merged into the duotone layer.
